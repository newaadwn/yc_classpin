# SOi 15페이지 의미 섹션 분석

2026-09-29. 코딩 어시스턴트가 실제 15개 슬라이드 이미지를 읽고 문맥과 배치를 함께 검토해 작성한 자료별 주석이다. 자동 서비스 모델 재실행 결과나 강사 승인 결과가 아니다. 슬라이드의 주장·수치의 사실성을 검증한 것은 아니다. 좌표는 정규화된 사각형이며 여백·경계의 핀은 미분류로 유지한다. 원본을 교체하면 재검토해야 한다.

## 1페이지

- 서비스 정의: 이미지 위 음성·텍스트 태깅이라는 제품 정의
- 제품 사용 이미지: 화면 예시를 통한 사용 경험 소개

## 2페이지

- 시장 규모와 성장성: 시장 비중과 성장 전망은 시장 기회를 설명하는 근거
- 친밀형 SNS 수요: BeReal과 Locket 사례로 친밀한 관계 수요 제시
- 시장 기회 결론: 관계 중심 수요와 시장 성장이라는 결론

## 3페이지

- 기존 SNS의 한계: 게시 부담·연결감 부족·관계 스트레스를 하나의 문제로 제시
- 소수 인간관계 선호: 깊은 관계 선호 설문과 도표
- 핵심 결론: 관계의 양보다 진짜 연결을 원한다는 주장

## 4페이지

- 리텐션 문제 정의: 성장에도 참여 동기가 부족하다는 핵심 주장
- 초기 성장 사례: 기존 서비스들의 초기 확산
- 참여 저하와 이탈: 성장 이후 이용 감소 사례

## 5페이지

- 이탈자 인터뷰: 게시 부담에 대한 인터뷰 근거
- 이탈의 구조: 게시 부담에서 콘텐츠 감소와 이탈로 이어지는 흐름
- SOi의 해결 방향: 게시하지 않아도 반응할 수 있도록 참여 장벽을 낮춤

## 6페이지

- 위치 기반 멀티미디어 반응: 사진의 특정 위치에 음성·텍스트 반응을 연결
- 앱 사용 예시: 실제 화면 형태로 보여주는 서비스 경험
- 참여 장벽 완화: 게시 중심에서 태깅 중심 참여로 전환

## 7페이지

- 목적 기반 방 생성: Purpose Room으로 공유 동기를 형성
- 간편한 게시물 공유: Quick Post로 업로드 부담을 낮춤
- 통합 피드: Cross Feed로 방의 콘텐츠를 통합
- 장면 위 태깅 답글: Tagged Reply로 반응을 축적해 참여 루프 완성

## 8페이지

- 현재 B2B 제안: 유료 멤버십 커뮤니티의 관계 지속 지원
- 향후 B2B 확장: 팬덤·건설 현장·웰니스로 적용 범위 확장

## 9페이지

- 시장 규모 산정: TAM·SAM·SOM 산정과 산식
- 확장 및 초기 타깃: 유료 커뮤니티 확장 타깃과 초기 대학생 집단
- 시장 범위 구조: 포함 관계를 표현하는 중첩 시장 도식

## 10페이지

- 경쟁 포지셔닝: 관계 친밀도와 대화 지속성에 따른 비교
- 기능 차별화: 경쟁 서비스와 기능별 비교표
- 차별화 결론: 지속형 프라이빗 커뮤니케이션이라는 가치

## 11페이지

- 현재 MVP와 기반 역량: 멀티모달 태깅 구현과 선행기술·특허 검토
- 음성 처리 확장: 음성 전사·요약·키워드 추출 및 저장
- 태그 위치 추천 확장: 시각 인식으로 핵심 포인트와 후보 좌표 생성

## 12페이지

- 국내 사용자 검증: 인터뷰·베타·파일럿의 참여 및 유지 지표
- 사용자 반응: 사용자가 인식한 관계와 기록 가치
- 해외 수요 검증: 해외 사용자 테스트·언어 지원·확장 수요

## 13페이지

- 성장 전략 방향: 사용자 검증 후 단계적으로 확장한다는 원칙
- 개발·사업 확장 준비: MVP 고도화·법률 기반·확장기술 검증
- 사용자 확보·파일럿·출시 후 개선: 검증 사용자 확보부터 파일럿과 지속 개선까지

## 14페이지

- 핵심 팀 역량: 기획·디자인·개발 구성원의 경험
- 기술·사업 자문: 외부 자문과 지원 역량
- 팀 성과: 지원사업 선정과 수상 이력

## 15페이지

- 문제: 기존 SNS의 참여 지속성과 맥락 부족
- 해결책: 태깅 중심 참여와 대화 축적
- 핵심 기술: 좌표·음성 정규화·시각 추천·구조화 데이터
