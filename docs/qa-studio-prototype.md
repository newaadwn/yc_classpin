150핀 시뮬레이션을 비활성화하여 fixture 중복을 방지한다. 완료 콜백은 Studio 메모리에만 연결.
전체화면의 보조 동작은 영역 편집 대신 해당 페이지 주제 보기. 기존 지도에서는 영역 편집 유지.

설명 완료와 이해 반응 분리. 청중 미리보기에서 가상 참여자를 선택해 이해/추가 설명 반응을 바꾼다.

기존 질문 지도 링크 유지, 기존 UI/DB/API/실제 발표 페이지 동기화 변경 없음.
# 자료 목록 진입 모션 (2026-09-29 사용자 요청)

- 기존 폴더 자료 목록을 시작 화면으로 유지한다.
- 자료 카드 선택 → 중앙 이동(440ms) → Studio에서 슬라이드 순차 펼침(600ms + 순차 지연).
- 카드의 별도 링크로 기존 강사 화면에도 접근할 수 있다. Studio는 자료 목록 복귀 링크를 제공한다.
- reduced-motion 사용자는 모션을 생략한다. Ctrl/Cmd 클릭은 일반 새 탭 링크 동작을 유지한다.
- 이 변경은 프론트엔드 진입 효과만 다루며 데이터베이스를 변경하지 않는다.

## QUESTION TIME 대시보드 개정 (2026-09-29 사용자 요청)

- 제목을 `QUESTION TIME`으로, 화면 전체를 검은 배경으로 바꿨다. 어두운 표면·계열색 토큰이 기존 디자인 토큰에 없어
  `content-dashboard.module.css` 안에서만 정의한다 (계열색 4개 + 기타 회색, dataviz 검증 통과).
- 원그래프를 SVG 도넛으로 바꿔 조각 안에 백분율, 가운데에 전체 질문 수를 직접 표시한다. 막대는 22px 두께에
  이름·값을 크게, 영역 막대에는 페이지 배지(예: `3p`)를 붙였다. 범주 순서와 색은 고정이다.
- 그래프(도넛 조각·범례·범주 막대·영역 막대)를 누르면 질문 목록이 아니라 **해당 페이지 보기**가 바로 열린다.
  범주는 질문이 가장 많은 페이지부터 열고 같은 범주의 다른 페이지로 ‹ › 이동한다. 영역 막대는 그 영역 사각형을
  슬라이드 위에 표시하고 영역 밖 핀은 흐리게 한다. 핀이나 오른쪽 목록을 누르면 원문이 보인다.
- `발표 창을 이 페이지로`는 같은 브라우저의 강사 슬라이드쇼·학생 데모 탭에 기존 `page` 이벤트를 보낸다. 누르기 전에는
  발표 페이지를 바꾸지 않는다. Esc는 페이지 보기 → 대시보드 순서로 닫는다.
- 집계 방식·데이터·DB는 바꾸지 않았다 (원본 질문 수 기준, 수동 분류). `scripts/verify-content-dashboard.cjs`의
  선택자(대화상자 이름, article 7개, `질문 N개 보기`, `aside>strong`)는 유지했다.
- 검증: `tsc --noEmit`, 변경 파일 ESLint 통과. 실제 화면은 클라우드 작업 공간에서 같은 컴포넌트를 가상 세션(15쪽,
  가상 질문 100개, 수동 영역)으로 띄워 1600px·390px에서 확인했다. 이 PC의 실제 Studio 화면에서는 아직 확인하지 않았다.
- 2026-09-29 (Claude): 요약 옆칸에 `묶음 후 N건`을 추가했다. 값은 지도·강사 패널과 같은 `question-condense.ts`
  결과(문구·영역 규칙 + 임베딩 유사도)이며 그래프 집계는 여전히 원본 질문 수 기준이다. 실제 화면 확인은 미실시.
- 2026-09-29 (Claude, 사용자 요청): 도구 막대에 집계 기준 전환 `전체 질문 / 묶음 · 파란 핀`을 넣었다. 기본은 전체 질문(원문 1건 = 1)이고,
  묶음 기준은 지도의 파란 핀과 같은 `question-condense.ts` 묶음 1개 = 1로 세며 묶음은 **대표 질문의 핀 위치**로 범주·영역을 정한다.
  묶음 기준에서는 도넛 가운데·범례·막대·요약이 `N묶음`으로 바뀌고, 미처리는 묶음 안에 미처리 원문이 하나라도 있으면 센다.
  페이지 보기 목록은 묶음마다 대표 문구 1개에 `같은 뜻 N건`을 붙이고, 선택하면 나머지 원문을 아래에 펼치며 같은 묶음 핀을 강조한다.
  핀을 누르면 그 핀이 속한 묶음이 선택된다. 기준을 바꾸면 페이지 보기는 닫힌다. 그래프 집계 방식·데이터·DB는 그대로다.
  검증: 이 PC에서 `tsc --noEmit`, 파일 ESLint 통과. 클라우드 작업 공간의 가상 세션(100문항)에서 전환·범례·영역 막대·핀 선택·
  모바일 폭을 확인했고(원문 100 → 묶음 46), 실제 Studio 화면과 임베딩 연결 상태에서는 아직 확인하지 않았다.
