# 강의 후 의미 기반 질문 보고서

2026-10-13 사용자 요청: 메인 서비스와 병합하지 않고 QA Studio의 분석과 의미 기반 핀 레이블링을 강의 후 결과보고서로 분리한다.

첫 구현은 폴더 Insights에서 자료별 보고서 초안을 연다. 현재 소유자 세션 저장소의 질문만 사용하며 Studio fixture, 학생 데모 이벤트, 특정 자료에 하드코딩한 영역을 가져오지 않는다. 질문/자료는 화면 진입 시 복사한다. 묶음은 기존 question-condense와 검토된 영역을 사용한다. 분석 진행 중인 초안이며 영구 확정본이나 PDF가 아니다.

원본 질문 수, 묶음 수, 미답변 수를 분리한다. 영역 레이블 → 질문 묶음 → 원문/핀으로 조회한다. 영역이 없으면 미분류로 남긴다. 자동 묶음은 제안으로 표시한다. 질문 상태 변경, 발표 제어, 가상 질문 생성은 제공하지 않는다.

후속: 분석 및 레이블의 불변 snapshot을 기존 보고서 revision 계약에 연결하고 강사 검토/확정과 PDF에 반영한다. 메인 데이터 연결과 권한을 검증하기 전 전달 완료로 표시하지 않는다.

- 근거 창에서 원문/답변 상태/공감/슬라이드 핀을 확인. 강사가 확인 체크 후 추가 설명·예시·자료 수정·추가 답변·조치 불필요를 선택. 조치 불필요는 다른 선택과 배타적.
- 계정+자료+Studio/실제 보고서 구분으로 브라우저 localStorage 초안 저장. 서버 확정/기기 간 동기화/학생 전송은 제공하지 않음. Studio 가상 데이터의 조치는 실제 보고서와 분리.
- 저장 당시 질문 ID 목록과 재검토 근거가 달라지면 변경 안내. 열려 있는 근거는 snapshot으로 유지. 저장 실패 시 성공 표시하지 않음.
- 분석 판단이나 질문 상태를 자동 변경하지 않음. TOP 3가 없으면 빈 상태 안내.
- 출처: 순위 결정, 근거 확인 체크, 후속 조치 선택/초안 저장은 자체 구현. 기존 의미 묶음과 SlideCanvas 재사용.

## 분류별 분석 보드 · 2026-10-13 사용자 승인
질문 유형/답변 상태는 질문별로 분리하므로 한 페이지가 여러 묶음에 나타날 수 있다. 각 보드에는 해당 질문과 페이지/의미 묶음만 포함하며 원본 페이지 번호를 유지한다. 내용 범주는 검토·확정된 의미 영역명 기준이며 임의 AI 상위 범주를 생성하지 않는다. 영역 미지정 질문은 내용 미분류에 남긴다. 기존 페이지 의미 영역 분석/검토 경로를 제공하고 결과를 다시 생성하면 확정 레이블이 반영된다. 분류 프레임 옆의 분석 보드는 클릭해 전체화면으로 확인한다. 핀 필터는 기본 좌상단, 드래그 및 방향키 이동을 지원한다. 순수 모델 테스트와 scripts/verify-scoped-analysis.cjs로 질문 격리·전체화면·필터 이동을 검증한다.

분류별 보드 표시 변경: 캔버스에는 회색 말풍선의 AI 요약 제목과 해당 묶음의 대표 질문·답변 상태를 바탕으로 구성한 한 문단을 표시한다. 신규 LLM 호출은 없으며 기존 분석 결과를 문장으로 구성한다. 자세히 보기는 기존 수치/분포/원문 근거 전체화면을 연다.

## 실제 묶음 AI 요약 · 사용자 요청 2026-10-13
정형 대표 질문 문구를 제거한다. 각 묶음의 모든 페이지 텍스트(원본 추출/OCR)와 모든 질문을 로컬 Qwen3 4B에 전달해 관심 주제와 구체적 보완 제안을 한 문단으로 생성한다. 큰 입력은 전체 레코드를 청크 분석한 후 재귀 종합하며 묵시적 절삭을 하지 않는다. 자료/OCR/질문 속 지시는 신뢰하지 않고 발표자 노트/사용자 신원은 전달하지 않는다. 자료 추출 또는 모델 오류는 실패·재시도로 표시하며 정형 문구로 성공을 대체하지 않는다. 계정·입력별 요청 중복 제거 및 모델 직렬 실행을 적용한다.

검증: 실제 로컬 Qwen3 4B에 두 페이지/두 관심 주제를 입력해 종합 요약 생성 확인. 초안 생성 후 동일 근거로 재검수해 지원되지 않는 정책/기능을 제거하도록 구성한다. 브라우저 테스트는 모델 응답을 모킹하여 전체 자료·복수 질문 전달, 실패 및 재시도, 결과 문단 표시를 검증했다 (`scripts/verify-ai-scope-summary.cjs`). 모델 검증과 UI 모킹 검증은 구분한다.

말풍선 외곽 배치: 분류 프레임은 슬라이드만 둘러싸며 요약은 전체 자료 묶음의 왼쪽·오른쪽·아래 외곽에 배치한다. 말풍선 간 겹침을 피하고 화면 맞춤에 포함한다. 꼬리는 해당 프레임 방향을 향하며 이동·확대·상세보기 동작은 유지한다.

최신 배치 수정: 사용자 요청에 따라 말풍선을 다시 섹션 프레임 안에 포함한다. 섹션마다 왼쪽·오른쪽·아래로 위치를 달리하고 해당 공간을 확보해 슬라이드와 겹치지 않게 한다. 앞선 외곽 배치 결정을 대체한다.

사용자 요청: 연결 실패 중 화면 시연을 위해 말풍선은 분류별 예시 요약을 기본 표시한다. 실제 분석 결과가 아님을 명시하고 자동 모델 호출은 중단한다. 실제 AI 분석 실행/실패 시 예시 복귀 버튼을 제공한다. 수치/원문 상세는 기존 실제 분석 데이터를 유지한다.

## 대시보드 가독성 개선
질문 유형은 구성비 막대와 전체 범례/건수/비율, 페이지 분포는 원본 순서의 밀도 지도(페이지·질문 수 병기, 24페이지 초과 시 표시 범위 안내), 답변 상태는 미답변/답변됨/해결됨 도넛과 답변 처리율로 표시한다. 반복 주제와 최다 공감은 핵심 수치를 강조한다. 색만으로 정보를 전달하지 않고 라벨/숫자를 함께 제공한다. 상세 비교 막대와 원문 근거 흐름은 유지한다. 1366×768·1920×1080의 전체 카드 노출과 상세/뒤로/Escape를 브라우저에서 확인했다.
