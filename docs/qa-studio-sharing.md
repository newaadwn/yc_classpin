# QA Studio / 강의 결과 분석 공유 버전

## 실행
1. Node.js 의존성 설치: `npm ci`
2. `.env.example`을 참고해 `.env.local` 구성. 실제 비밀키는 저장소에 포함하지 않습니다.
3. 로컬 Supabase를 사용하는 경우 Docker 실행 후 `npm run supabase:start`.
4. 개발 화면 실행: `npm run dev -- --port 3001 --webpack`
5. 로그인 후 자료의 결과리포트 생성 버튼으로 진입합니다. 샘플은 `/admin/session/soi-demo/qa-studio`에서 확인할 수 있습니다.

Windows에서 Node 메모리가 부족하면 실행 전에 PowerShell에서 `$env:NODE_OPTIONS='--max-old-space-size=1536'`을 설정하세요. PC 전체 여유 메모리도 필요합니다.

## 확인할 기능
- QA Studio의 슬라이드·질문 분류와 의미 영역, 묶음별 요약 말풍선
- 드래그 가능한 상단 필터 및 하단 분류 도구
- 우클릭 AI 채팅 시연: `2, 4, 6페이지 섹션 모아서 분석해`
- 요청 페이지 묶음 생성과 타이핑 효과의 예시 요약 (실제 AI 호출 아님)
- 강의 인사이트: 질문 집중 내용, 필요한 설명, 보완 제안 → 질문 근거
- TOP 3 근거 확인 및 후속 조치 선택, 상세 통계

## 한계와 데이터
- 상단 보완 제안은 현재 질문 유형 집계에 따른 규칙 기반 제안입니다.
- 예시 요약에는 예시 표시가 있습니다. 실제 모델 연결은 별도 로컬 분석 서비스 설정이 필요합니다. `services/local-sections/README.md` 및 관련 분석 문서를 참고하세요.
- 생성 보고서는 브라우저 초안이며 다른 사람의 브라우저로 자동 공유되지 않습니다. 채팅으로 추가한 묶음은 현재 화면 임시 상태입니다.
- 질문 수를 이해도나 참여율로 해석하지 않습니다.
- GitHub 업로드는 코드 공유이며 서비스 공개 URL 배포는 포함하지 않습니다.

## 검증
변경 화면의 TypeScript 검사, 대상 린트, 1366×768 및 1920×1080 브라우저 요약·상세 탐색을 확인했습니다. 전체 프로덕션 빌드/새 DB 마이그레이션 재생은 이번 공유 시 수행하지 않았습니다.
