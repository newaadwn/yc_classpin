# feature-dev UI의 로컬 적용

2026-10-13 사용자 요청에 따라 Team-Newdawn/ClassPin-FE feature-dev의 UI를 현재 AI_Develop 작업 폴더에 통합했다. 원격 브랜치 병합/푸시는 수행하지 않았다.

출처: https://github.com/Team-Newdawn/ClassPin-FE/commit/e00739aead3abe27efeb5135797f4f43c21e2bb5

- 가져온 UI: 폴더 생성 색상/용도, 자료 상세 패널, OhPin 브랜딩, 강의 페이지 번호 이동/자동 재생/노트 자동 저장, 모바일 강사 질문 패널.
- 자체 통합: 자료 상세 패널과 강의 화면에 QA Studio/결과보고서 링크 추가. 분석 업로드 설정과 기존 보고서/캔버스 경로 유지.
- 데이터 연결: 기존 로컬 Supabase 저장 계층에 폴더 목적과 발표 자동 재생 필드 연결. REST 전환 및 CI/CD 변경은 적용하지 않음.
- 로컬 DB: upstream 마이그레이션 3개 적용. 기존 폴더 3개와 강의 17개 보존, 두 테이블의 RLS 유지 확인. 데이터 초기화하지 않음.
- 검증: 타입 검사, 변경 파일 ESLint, 관련 모델 테스트 15개, 프로덕션 빌드 통과. 폴더 생성/옵션 저장/테스트 폴더 삭제, 자료 선택/격자/목록/Insights, 자동 재생 저장, 메모 자동 저장/원복, 패널 크기 조절, 질문 상세/모바일 패널 통과. QA Studio 보드 생성/이동/확대/크기 조절/삭제, 보고서 근거 선택, 100% 요약 화면도 통과.
- 사용법: /admin/dashboard → 폴더 → 자료 선택 → 상세 패널에서 슬라이드 열기, QA Studio, 결과보고서 선택.
- 복구용 원본: output/ui-port/manifest.json 및 각 local 파일.
- 검증 한계: 필수 ponytail/ponytail-review 스킬 미설치로 직접 검증. 기존 데이터 보존을 위해 DB reset 대신 추가 마이그레이션과 실제 저장 동작 검증.

## 분석 화면 스타일 통일
- QA Studio와 결과보고서에 공통 OhPin 헤더, 자료명, 분석 작업 공간 탭을 적용했다.
- 바깥 도구 모음과 패널의 색상/테두리/버튼을 기존 관리자 UI 토큰으로 통일했다.
- 사용자 지정 보존 범위: 중앙 점선 캔버스, 분석 보드, 슬라이드 카드, 빨강/파랑 핀과 캔버스 내부 조작 UI. 해당 컴포넌트는 수정하지 않았다.
- 데스크톱 스크린샷 및 모바일 가로 넘침, QA Studio 15장 유지, 대시보드 확대/상세/복귀 검증. 데모의 보고서 링크는 실제 자료를 고를 수 있는 대시보드로 연결한다.
