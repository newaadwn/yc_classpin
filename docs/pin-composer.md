# PIN 위치 기반 질문 입력창

2026-09-15 사용자 요청으로 승인된 UI 변경.

- 중앙 모달 대신 선택한 PIN 좌표 옆에 작은 비모달 입력창을 표시한다.
- 슬라이드를 흐리거나 어둡게 하지 않는다. 화면 가장자리에서는 좌우를 전환하고 화면 안으로 제한한다.
- PIN 좌표에 고정된 꼬리와 작은 둥근 몸체를 함께 그리며 420ms 동안 입력창 크기로 펼친다. 중간 파랑 전환과 텍스트 확대는 없고 내용만 마지막에 나타난다. 원래 핀은 열린 동안 숨기며 reduced-motion에서는 모양 애니메이션을 생략한다.
- 기존 카테고리, 마커, 질문 수정/전송, 오류, 답변 조회를 유지한다. 데이터·권한·AI 경로는 변경하지 않는다.
- 닫기/Escape를 제공하며 새 질문 초안은 기존 방식으로 유지한다. 작은 화면과 키보드 표시 시 입력창 내부 스크롤을 지원한다.
- 말풍선 꼬리는 PIN 좌표를 가리킨다. 좌우 공간이 부족하면 위아래에 배치한다. 투명 바깥 영역을 탭하면 닫기만 수행하며 그 탭으로 새 PIN을 만들지 않는다.
- 실제 로컬 참여자 화면에서 위치, 초안 유지, 입력, 화면 경계를 검증한다. 기존 로컬 데이터 보호를 위해 DB reset은 실행하지 않는다.
- 개발 모드 effect 재실행에서도 애니메이션을 복구해야 한다. 최종 화면뿐 아니라 열리는 동안 SVG 몸체 폭 증가 및 reduced-motion 즉시 표시를 프레임 단위로 검증한다.
- 강사 라이브 화면의 PIN 상세 조회도 공통 PinComposer를 사용한다. 질문/답변 내용과 닫기를 유지하며 별도 발표 화면의 기존 모달은 변경하지 않는다.
