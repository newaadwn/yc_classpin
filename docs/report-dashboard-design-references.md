# 결과보고서 대시보드 — 대표 보고용 구현 출처 기록

기준일: 2026-10-13. 본 문서는 디자인 참고와 자체 구현의 구분이며, 경쟁 서비스와의 기능 동등성 또는 성능 우위를 주장하지 않는다.

## 참고한 서비스와 적용 범위

| 서비스 / 공식 출처 | 참고한 원칙 | 이번 적용 | 가져오지 않은 것 |
|---|---|---|---|
| [Dovetail AI Dashboards](https://dovetail.com/product/ai-dashboards/) | 정성 피드백을 주제별 규모와 연결 | 왼쪽 질문 주제별 건수 막대와 상세 근거 패널 | 코드·화면 복제, 감정 분석, NPS/CSAT |
| [Hotjar Engagement Zones](https://www.hotjar.com/heatmaps/engagement-zones/) | 원본 화면 위 위치별 상호작용 탐색 | 슬라이드별 질문 위치와 선택 페이지 강조 | 클릭·스크롤 수집, 연속 밀도 히트맵 |
| [Slido Event Analytics](https://blog.slido.com/event-analytics/) | 행사 종료 후 참여 결과 요약 | 원본 질문·묶음·미답변·페이지 수 카드 | 참여 인원 추정, 참여율, 이해도 점수 |

공식 제품 소개에서 정보 구조를 참고했다. 동일 UI를 재현하거나 코드·이미지 자산을 복사하지 않았다.

## 자체 개발 및 기존 작업 재사용

- QA Studio에서 사용하던 SpatialCanvas: 슬라이드 자유 배치, 확대·축소, 페이지별 원본/묶음 핀.
- question-condense: 문구·영역·질문 의도와 임베딩 유사도를 이용한 묶음 제안. 강사의 분리 설정을 존중.
- 강사 검토를 거친 슬라이드 의미 영역 레이블 및 핀 좌표 연결.
- 이번 신규 연결: 주제 선택 → 캔버스의 관련 페이지 강조 → 우측 슬라이드·원문 조회. 캔버스에서 페이지 선택도 상세 패널로 연결.
- 보고서 읽기 전용 모드: 시뮬레이션·답변 처리·발표 제어를 제공하지 않는다. 미답변 묶음 필터와 빈 결과 안내.

## 구현 범위와 한계

### 대시보드 보강 — 구현 완료

- Dovetail 참고: 페이지·의미 영역별 원문 건수, 반복 묶음 대표 질문, 선택한 집계의 원문 목록. 원문에서 슬라이드로 연결한다.
- Hotjar 참고: 질문 집중 페이지/영역 순위에서 기존 슬라이드 핀 화면으로 이동. 연속 밀도 히트맵과 특정 핀 자동 선택은 미구현이다.
- Slido 참고: 질문 발생 페이지, 질문 유형 비중, 미답변/답변됨/해결됨, 공감 많은 미답변 원문.
- 자체 구현: 기존 의미 묶음 방식별 집계, 묶음 전후 숫자, 미분류 항목, 분석 상태 표시. UI에 있는 모든 통계는 현재 입력 질문에서 코드로 계산한다.
- 미구현/후속: 기간 비교, 레이블 검토 상태의 개별 출처 추적, 불변 보고서 revision, PDF. 참여율과 이해도 점수는 필요한 데이터가 없어 생성하지 않는다.

### QA Studio 내부 확장 전환 (2026-10-13)

사용자가 제시한 Prezi의 공간 탐색 개념을 참고했다. 대시보드·주제 분석·결과 요약 보드를 슬라이드와 동일한 world 좌표에 생성한다. 보드는 왼쪽에 순차 배치하며 기존 카메라가 새 보드를 확대하고 전체 보기에 모두 포함한다. 제목 드래그 및 방향키 이동을 지원한다. 같은 종류의 생성 버튼은 기존 보드로 이동한다. 별도 오버레이를 사용하지 않으며 Prezi 코드·자산을 사용하지 않았다. 보드 배치는 현재 화면 메모리 전용이다. Studio의 가상 질문이 포함될 수 있음을 표시하고 확정 보고서로 취급하지 않는다.

자료와 질문은 진입 시 복사하나 레이블·묶음은 분석 중 갱신되는 초안이다. 영구 revision, 확정, PDF는 아직 연결되지 않았다. 임베딩 서버가 없으면 규칙 기반 묶음이라는 상태를 표시한다. 독립 보고서 화면의 막대는 질문 묶음별 원문 수이며, Studio 대시보드는 페이지·영역·질문 유형별 원문 집계를 추가로 제공한다. 대표 제목은 기존 질문 의도와 원문을 활용하며 새 AI 요약을 생성하지 않는다.

보고 시 권장 표현: “Dovetail의 주제 분석, Hotjar의 위치 기반 탐색, Slido의 종료 후 요약 방식을 참고하고, 자사 QA Studio의 의미 영역·질문 묶음·슬라이드 핀 탐색을 연결한 강의 분석 대시보드입니다.”

### 2026-10-13: 한 화면 요약과 상세 탐색
- QA Studio 대시보드를 지표 6개와 요약 카드 8개로 구성. 데스크톱 100% 배율에서 전체 요약을 한 화면에 제공.
- 카드 클릭으로 개별 상세 차트, 원문 근거, 슬라이드 이동을 제공. 전체 요약 복귀 시 선택 카드에 키보드 포커스를 복원.
- 자체 구현: 반응형 요약/상세 전환과 QA Studio 캔버스 연결. 기존 참고 앱의 소스 코드를 사용하지 않음.
- 검증: 1366×768 및 1920×1080에서 요약 카드 노출, 상세 원문 5건, 요약 복귀, Esc 캔버스 복귀.

### Slido 기반 강의 인사이트 재구성 (2026-10-13)
- Slido의 상단 지표 → 질문 분석 → 원문 탐색 구조를 참고해 현황 4개를 우선 배치한다.
- 자체 구현: 슬라이드 썸네일·질문 집중도 지도, 다시 설명할 내용 TOP 3 → 근거·후속 조치, 질문 데이터에서 계산한 강의 관찰 문장.
- 질문 유형은 비율 차트, 답변 현황은 도넛, 반복·공감 질문은 요약 카드로 표시한다. 기존 8개 상세 항목과 생성 시 선택 항목을 유지한다.
- 강의 관찰 문장은 집계 기반으로 작성되며 AI 생성이라고 표시하지 않는다. 캔버스의 AI 요약 말풍선·사용자 요청 묶음 기능은 유지한다.
- 1366×768, 1920×1080 요약 노출과 상세 원문·복귀 동작 검증. 원본 이미지로 작은 썸네일을 표시하며 별도 이미지 최적화는 적용하지 않았다.

### 컴팩트 대시보드
기본 화면은 핵심 지표 3개, 질문 유형, TOP 3, 집계 기반 총평으로 축소. 질문 지도와 보조 통계는 접힌 세부 분석으로 이동. 반복·공감 근거는 TOP 3에 통합. 1366×768 및 1920×1080 브라우저 검증 통과.
